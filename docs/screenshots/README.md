# Application Screenshots

Place genuine screenshots captured from the running application here:

1. **Homepage / Landing Page:**
   - Filename: `landing-page.png`
   - Content: Full desktop view of the hero section and value proposition at `http://localhost:5173`.

2. **Enquiry Management Workspace:**
   - Filename: `enquiry-workspace.png`
   - Content: Enquiry ledger at `http://localhost:5173/#workspace` displaying operational metrics, filters, and incoming inquiries.

3. **Bookings & Schedule Board:**
   - Filename: `bookings-board.png`
   - Content: Bookings tab at `http://localhost:5173/#workspace` showing confirmed and pending service bookings.

4. **Enquiry Inspection & Conversion Modal (Optional):**
   - Filename: `enquiry-modal.png`
   - Content: Detailed inspection modal showing customer enquiry details and the booking conversion drawer.

### How to Capture
1. Start the local server: `npm run dev`
2. Open `http://localhost:5173` in your browser.
3. Use your system screenshot utility (e.g. `Win + Shift + S` on Windows, `Cmd + Shift + 4` on macOS) or browser DevTools (`Ctrl + Shift + P` -> "Capture full size screenshot").
4. Save image files into this directory (`docs/screenshots/`) using the filenames specified above.
